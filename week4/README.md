# Week 4: Rules & Memory

## Requests to Copy

> Open your agent in your team's capstone repo for these.

Save your rules, in your words:

```text
Save these rules to AGENTS.md in the project root. Use my wording.
- <your rule>
- <your rule>
- <your rule>
```

Then start a new session and give your agent a small task that touches your rules. Review what it did and read the diff.

At the end of a session:

```text
Suggest AGENTS.md updates. Only things you had to learn from me.
```

Accept or reject each suggestion. Save the ones you accept under a `## Learned Behavior` section in your AGENTS.md.
