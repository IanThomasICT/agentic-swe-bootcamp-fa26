# Agentic Software Engineering Bootcamp (Fall 2026)

Code and exercises for the Newman University Agentic Software Engineering Bootcamp.

| Week | Topic | Folder |
|------|-------|--------|
| 2 | Build a coding agent: an LLM, four tools, and a loop, in TypeScript with Bun and OpenRouter | [week2/coding-agent](week2/coding-agent/) |

## Setup

Clone this repo, then run `bash setup.sh` (Mac, Linux, Git Bash) or `.\setup.bat` (Windows). See [week2/coding-agent](week2/coding-agent/) for details.

## Prerequisites

- [Bun](https://bun.sh/) (Week 2; setup installs it)
- A free [OpenRouter](https://openrouter.ai/keys) key (Week 2)
- [git](https://git-scm.com/downloads) (setup installs it) and [gh](https://cli.github.com/)
